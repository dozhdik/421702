# Постановка задачи

Вариант 9: учёт договоров страхования. Разработать приложение Python + SQLite с настольным интерфейсом Tkinter/ttk.

Организации, сотрудники и агенты должны поддерживать просмотр, добавление, редактирование и удаление. Коллективный договор связывает организацию, одного агента, сотрудников организации и суммы по категориям риска. Предусмотрены индивидуальные договоры и учёт фактических страховых случаев.

Обязательные отчёты на выбранную дату:

1. Действующие договоры выбранной организации: название, адрес, дата, номер и период договора.
2. Агенты, ведущие действующие договоры организации: дата, фирма, ФИО, телефон, без повторов.
3. Суммы по категориям сотрудников: дата, категория и сумма; показывать договор, чтобы различать суммы.

Дата заключения считается началом действия договора; границы срока включены. Для отчёта № 3 фильтр организации необязателен.
