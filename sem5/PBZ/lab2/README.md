# Учёт договоров страхования

Консольное приложение Python + SQLite для лабораторной работы № 2, вариант 9. Требования к этой версии сохранены в [docs/CODEX_TASK.md](docs/CODEX_TASK.md).

## Запуск

Требуется Python 3.10 или новее. Из каталога проекта:

```bash
python3 main.py
```

Выберите номер пункта и нажмите Enter. В подменю `0` возвращает назад, в главном меню завершает работу. При редактировании пустой ввод сохраняет прежнее значение. Перед удалением показывается запись и запрашивается подтверждение. Для ссылок на организации, агентов и сотрудников выводятся списки с ID.

При первом запуске создаётся `data/insurance.db`. Существующая база не очищается. Для работы с другой базой можно задать переменную `INSURANCE_DB_PATH`. Схема дополняется только новыми таблицами и индексами; старые данные не пересоздаются.

В пункте 9 главного меню можно добавить демонстрационные данные. Повторный запуск не создаёт дубликаты. Альтернативная команда:

```bash
python3 main.py --seed
```

## Возможности

- Просмотр, добавление, изменение и удаление организаций, сотрудников и страховых агентов.
- Создание и изменение коллективного договора со списком сотрудников и суммами по категориям; добавление и удаление сотрудников, управление суммами.
- Отчёты на выбранную дату: договоры организации, её агенты без повторов и суммы по категориям с номерами договоров. В третьем отчёте код организации необязателен.
- Просмотр и изменение индивидуальных договоров и страховых случаев, сохранённые из предыдущей версии.

Дата вводится в формате `YYYY-MM-DD`; начало и конец договора включены в период действия. Дата заключения считается датой начала. Сумма по категории — условие договора, фактический страховой случай хранится отдельно. В текущей модели дата страхового случая считается датой выплаты.

Организацию сотрудника и коллективного договора после создания менять нельзя. Для каждой категории сотрудников договора требуется сумма. Для удаления последнего сотрудника нужно удалить сам договор; организации и сотрудники с зависимостями защищены от удаления. Агент, связанный с договором, также не удаляется. Допускаются суммы от нуля с точностью до двух десятичных знаков.

В SQLite исходная сумма категории хранится как `REAL`; поэтому это учебное приложение, а не система для точных денежных расчётов. Ввод проверяется с помощью `Decimal`; отчёт показывает сохранённые значения без сложения. Индивидуальный договор хранит имя страхователя, даты, сумму и агента; отдельный страховой случай для него не реализован.

## Проверка

```bash
python3 -m unittest discover -s tests -v
```

Тесты используют временную базу. Для демонстрации загрузите примеры, затем в отчётах выберите организацию `9001` и дату `2026-11-03`: действуют договоры DEMO-001 и DEMO-002, их ведёт один агент, а выплаты по одинаковым категориям показываются отдельно для каждого договора.

Для отчёта по лабораторной можно использовать снимки терминала с меню, вводом и результатами запросов.
