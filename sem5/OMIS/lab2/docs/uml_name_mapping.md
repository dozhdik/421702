# Соответствие обязательной UML-модели и английской реализации

Дополнительные поля мягкого удаления: `Article.deleted_at` → `omis_blog/domain.py`, SQLite `Article.deleted_at`; `Article.deleted_by` → `omis_blog/domain.py`, SQLite `Article.deleted_by` с внешним ключом на `User.user_id`. Они расширяют исходный класс и не заменяют элементы диаграмм.

Имена из базовых диаграмм A/E/G/H сохранены по смыслу и составу. Таблица ниже фиксирует каждое исходное имя, включая поля, операции и интерфейсные состояния. Исключены направления развития F. Кириллические ключи существуют только в `scripts/legacy_name_map.py` для миграции старой БД.
