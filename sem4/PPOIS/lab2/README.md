# Управление складскими товарами

Десктопное приложение на Python с архитектурой MVC для управления базой данных складских товаров.

## Запуск

```bash
cd warehouse_app
python main.py
```

## Функциональность

- **Просмотр записей** с пагинацией (настраиваемое количество на странице)
- **Добавление записей** через диалоговое окно с валидацией
- **Поиск** по критериям (Вариант 6):
  - По названию товара ИЛИ количеству
  - По производителю ИЛИ УНП
  - По адресу склада
- **Удаление** по тем же критериям
- **Сохранение/загрузка** в XML (SAX для чтения, DOM для записи)
- **Генерация тестовых данных** (54 реалистичные записи)

## Требования

- Python 3.10+
- tkinter (стандартная библиотека)

## Структура данных

Каждая запись содержит:
- Название товара
- Производитель
- УНП производителя (строка, только цифры)
- Количество на складе (целое число ≥ 0 или "нет на складе")
- Адрес склада

## Архитектура

Строгое разделение MVC:
- **Model** ([model.py](warehouse_app/model.py)) — данные, XML-парсеры, бизнес-логика
- **View** ([view.py](warehouse_app/view.py)) — UI компоненты, диалоги
- **Controller** ([controller.py](warehouse_app/controller.py)) — связка Model-View
